# Stitch design export

Pulled from Google Stitch project **Tembra Audio DAW Design** on 2026-09-17.

- Project: https://stitch.withgoogle.com/projects/12040171611712589599
- Design system asset in Stitch: `assets/fb1657e091d24ba8a3e2aa5dee703ce3`, titled **Tembra Audio** (renamed from "Tembra Pro Audio" on 2026-09-17).

## Files

| File | What it is |
|------|------------|
| `DESIGN.md` | The design system verbatim from Stitch: token front matter (colors, typography, radii, spacing) plus the style guide prose. Source of truth for look and feel. |
| `theme.json` | The same tokens as machine-readable JSON, plus the hand-picked DAW colors named in the prose (surface levels, playhead, clip fills, pad wine tones, glow). Use this to generate the Compose theme. |
| `screens.json` | Manifest of every generated screen: Stitch screen ID, title, device, dimensions, download URLs. Used by the re-pull script below. |
| `screens/<screen>/<device>/index.html` | Full HTML + Tailwind source of each screen, as generated by Stitch. |
| `screens/<screen>/<device>/screenshot.jpg` | Full-resolution render of each screen. |

## Navigation model (derived from the screens)

- **Primary destinations:** Timeline, Tuner, Effects, Pads, Projects. Phone shows them as a bottom navigation bar with the active item as a raised lavender circle. Tablet shows them as a 64px left rail.
- **Secondary:** Remote (collaboration / remote control) appears on the tablet rail and in the original mockups; Users and Comments appear only in the mockups.
- **Global chrome:** top bar with menu, product name / screen title, cloud-sync icon, help, share, avatar. Transport bar (volume, return-to-zero, rewind, play/pause, fast-forward, timecode, speed chip, metronome toggle) is present on every DAW screen, including Effects and Export.
- **Inconsistency to resolve in the spec:** the tablet timeline rail labels the items "Tracks, Tuner, FX, Pads" while every other screen uses "Timeline, Tuner, Effects, Pads, Projects". Treat the latter as canonical.

## Build notes

- **Fonts:** Space Grotesk (500/600/700) for headlines, labels, timecode; Inter (400/500/600) for body and parameter readouts. Both are Google Fonts under the SIL Open Font License, fine for an open-source app. Bundle them; do not fetch at runtime.
- **Tabular numerals** are mandatory on every live-updating number (timecode, Hz, dB, BPM, pad index). In Compose this is `FontFeatureSettings("tnum")`.
- **Icons:** every screen uses Material Symbols Outlined (about 110 distinct glyphs, see `grep material-symbols-outlined screens/*/*/index.html`). Material Symbols are Apache-2.0 and available in Compose via `androidx.compose.material.icons` or as a bundled variable font.
- **Colour tokens:** `theme.json → namedColors` is a Material 3 dark tonal palette seeded from primary `#a78bfa`, secondary `#f472b6`, tertiary `#8b5cf6`, neutral `#0f0f12`. It maps one-to-one onto Compose `darkColorScheme(...)`. `dawSemanticColors` are the extra hand-picked values the prose relies on (surface levels 0–4, playhead, clip fills, pad wine tones); model them as a custom `LocalDawColors` composition local rather than overloading the Material scheme.
- **Radii:** the design system's scale is 4 / 8 / 12 / 16 / 24 px + pill. Track lanes and panels 12–16px, clips and pads 8–12px, chips and transport buttons pill.
- **Spacing:** 4/8px base module, 12px gutter, 16px page margin, 44px minimum touch target.
- **Elevation:** no drop shadows. Depth comes from stepping surface levels and 1px `#2B2A34` seams. The only glow is `0 0 12px rgba(167,139,250,0.25)` on active clips and nodes.
- **Per-screen drift:** the Tailwind config embedded in each HTML file is not identical across screens. Six screens carry no config at all, and the drum-sequencer phone screen uses its own slightly different palette (`#121116` surfaces, `#ec4899` active pad) plus amber and cyan step colours that are not in the design system. When these conflict, `DESIGN.md` and `theme.json` win.
- **Screenshot artefact:** `instrument-tuner/phone/screenshot.jpg` rendered with a serif fallback font and an overlapping title; the HTML is correct. Rely on the HTML for that screen.

## Re-pulling from Stitch

The Stitch MCP server is configured in Claude Code (`claude mcp get stitch`). To refresh after editing in Stitch:

1. Call `get_project` for `projects/12040171611712589599` and copy `designTheme.designMd` into `DESIGN.md` (keep the `name: Tembra Audio` line and the source comment).
2. Call `list_screens` and update the URLs in `screens.json` if any screen was regenerated.
3. Run the download step (Python, no dependencies):

```bash
cd design/stitch && python3 - <<'EOF'
import json, os, urllib.request
for s in json.load(open('screens.json'))['screens']:
    d = os.path.join('screens', s['slug']); os.makedirs(d, exist_ok=True)
    for key, fn in (('html', 'index.html'), ('screenshot', 'screenshot.jpg')):
        url = s[key] + ('=s0' if key == 'screenshot' else '')
        req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
        open(os.path.join(d, fn), 'wb').write(urllib.request.urlopen(req, timeout=120).read())
EOF
```

The `=s0` suffix asks Google's image host for the original size; without it you get a 512px thumbnail.
