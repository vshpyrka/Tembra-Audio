# Tasks: Instrument Tuner

**Input**: Design documents from `/specs/003-instrument-tuner/`

**Prerequisites**: plan.md, spec.md (clarified 2026-09-26, FR-001–FR-032), research.md (R1–R16), data-model.md (§1–§9), contracts/ (engine-c-abi-v2.md, tuner-audio-kotlin.md, tuner-domain.md, tuner-preferences.md, reference-sounds.md, microphone-permission.md, tuner-screen.md, design-system-additions.md), quickstart.md. Revised 2026-09-26 after `/speckit-analyze` (C1–C2, H1–H3, M1–M7, L1–L10 applied) and the user's request for test signals and a screenshot matrix (research R16).

**Tests**: Required. Constitution III (test-first, non-negotiable) and spec FR-028: every implementation task is preceded by the test that fails without it. Lanes, always with `--warning-mode all` from `app/`: `./gradlew engineHostTest` (Catch2, host), `./gradlew checkAndroidHost` (JVM), `./gradlew checkIos` (simulator), `./gradlew checkAndroidDevice` (device), plus `./gradlew :androidApp:connectedDebugAndroidTest` for the app module's instrumented test. Kotlin tests never link the engine; they use `FakeAudioEngine`, `FakeMicrophonePermission`, `FakeTunerPreferences` and a fake `ResourceReader`. The real engine is exercised only by the `:shared:engine` device and simulator lanes, including the test-signal end-to-end test.

**Organization**: Setup adds the one dependency, the assets and the platform declarations. Foundational builds what every story needs: the domain, the C ABI revision 2 skeleton with the engine state machine and the Kotlin `TunerAudio` seam, preferences and reference-sound types with their DI wiring, tokens and design-system components, and the permission interface with tested platform implementations. Each user story is then an independently testable increment: US1 (Auto Listen) adds the capture path, the meter, the test-signal tooling and the state screenshot matrix; US2 the selectors, presets and By Ear cards; US3 the tone path and audition; US4 the loop toggle; US5 the denied state and interruptions; US6 the expanded layout, input and screen-reader proof.
