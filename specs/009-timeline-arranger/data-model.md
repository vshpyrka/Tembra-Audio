# Data Model: Timeline Arranger (feature 009)

Every type is one file named after it (Principle VII), `internal` unless another module needs it.
Packages: `audio.tembra.core.project` (document, edits, tempo map, history), `audio.tembra.core.timeline`
(viewport geometry, ruler rules, snapping), `audio.tembra.engine` (seam, snapshots),
`audio.tembra.data.projects` (repository, index, import), `audio.tembra.ui.session`, `ui.timeline`,
`ui.transport`, `ui.projects`. Research decisions are cited as R-numbers from [research.md](research.md).

## 1. The project document (`:shared:core`, `project`)

All classes are `@Serializable` with explicit `@SerialName`; collections are
`kotlinx.collections.immutable` persistent types (R8). Nothing here names a device path.

| Type | Fields | Rules |
|---|---|---|
| `ProjectDocument` | `formatVersion: Int` (1), `project: Project` | the on-disk envelope; `formatVersion` is read first and drives `ProjectDocumentMigrations` |
| `Project` | `id: ProjectId`, `name: String`, `description: String = ""`, `key: MusicalKey? = null`, `tempo: Tempo`, `timeSignature: TimeSignature`, `tracks: PersistentList<Track>`, `assets: PersistentMap<AudioAssetId, AudioAsset>`, `masterVolume: Percent` (80), `metronomeOn: Boolean` (false) | `name` 1–60 chars trimmed, `description` ≤ 120; `tempo` reuses the metronome's `Tempo` (40–240), `timeSignature` the metronome's six; track ids unique; every clip's `assetId` exists in `assets`; `assets` has no entry no clip uses after an edit settles (see history rule). Grid and zoom are **not** here: they are the device-side `ProjectViewState` (§4), per spec FR-049 |
| `ProjectId`, `TrackId`, `ClipId` | `@JvmInline value class` over a UUID string | generated by `IdGenerator` (expect/actual is not needed: `kotlin.uuid.Uuid.random()`) |
| `AudioAssetId` | value class over the SHA-256 hex of the file bytes | the content identifier (FR-049); the same file imported twice is one asset |
| `AudioAsset` (the spec's "Audio Copy") | `id`, `fileName: String` (original name with extension), `format: AudioFormat` (Wav, Flac, Mp3), `channels: Int` (1–2), `sampleRate: Int`, `frames: Long`, `byteSize: Long` | immutable facts from `tembra_audio_inspect`; `durationSeconds = frames / sampleRate` |
| `Track` | `id`, `name: String` ("Track N"), `label: InstrumentLabel? = null`, `colorIndex: Int` (0–5), `gainDb: GainDb` (0.0), `muted: Boolean`, `soloed: Boolean`, `clips: PersistentList<Clip>` (sorted by `startBeats`) | `name` 1–40 chars, empty reverts to "Track N"; clips never overlap in **beats-at-current-tempo** after an edit (`ProjectEditor` enforces); `colorIndex` cycles through the six tints |
| `InstrumentLabel` | enum `Vocals, Guitar, Bass, Drums, Percussion, Keys, Synth, Strings, Brass, Woodwind, Loops, Other` with `displayName` and `icon` | FR-021 |
| `Clip` | `id`, `assetId`, `startBeats: Beats`, `offsetFrames: Long` (into the asset, at the asset's rate), `lengthFrames: Long` (at the asset's rate), `name: String` | `offset + length ≤ asset.frames`; `lengthFrames > 0`; name defaults to the asset file name without extension |
| `Beats` | value class over `Double` (quarter of the signature's beat unit resolution is not needed; plain beats of the unit) | `≥ 0`; arithmetic helpers `plus`, `minus`, `coerceAtLeast(0)` |
| `GainDb` | value class over `Float` | −∞ (represented as `NEG_INFINITY`) … +6.0; `toLinear()`; readout "+0.8dB", "−2.4dB", "−∞" |
| `Percent` | value class over `Int` | 0–100 |
| `MusicalKey` | enum of 24: `CMajor … BMajor, CMinor … BMinor` with `displayName` ("Cmaj", "F#maj", "Dmin"; sharps) | FR-003, FR-052 |
| `GridSize` | enum `Bar, Quarter, Eighth, Sixteenth, Off` with `beatsOf(signature)` | FR-018; `Off` snaps nothing |
| `ZoomLevel` | value class over `Double` pixels-per-beat at 1× density; `null` in `ProjectViewState` means "fit" | remembered per project on the device in `ProjectViewState` (§4), never in the document (spec FR-049, clarified 2026-10-13) |

### Derived values (pure functions, `core/project`)

- `Project.lengthBeats` = max over clips of `startBeats + tempoMap.framesToBeats(clip.lengthFrames at asset rate)`; `Project.lengthSeconds` through the tempo map; `0` for no clips.
- `Project.audibleTracks: Set<TrackId>` = the solo/mute truth table (FR-024): if any track is soloed, the soloed and not muted ones; otherwise every unmuted one.
- `Track.nextName(existing)` → "Track N" with N = max existing N + 1.
- `Project.unusedAssets` → asset ids no clip references (deleted by the repository once the history no longer holds them).

### Tempo map (`core/project/TempoMap`)

`TempoMap(tempo: Tempo, timeSignature: TimeSignature)`: `beatsToSeconds`, `secondsToBeats`,
`beatsToFrames(rate)`, `framesToBeats(frames, rate)`, `barOf(beats)`, `beatInBar(beats)`,
`beatsPerBar`. One entry by design (R3); the type is the only path from beats to time.

### Edits (`core/project/ProjectEdit`, sealed) and `ProjectEditor`

Every edit is a small data holder; `ProjectEditor.apply(project, edit): Project` is pure and
validates (returns `EditResult.Applied(project)` or `EditResult.Rejected(reason)`):

`AddTrack`, `RenameTrack(id, name)`, `SetLabel(id, label?)`, `SetGain(id, gainDb)`,
`SetMuted(id, Boolean)`, `SetSoloed(id, Boolean)`, `MoveTrack(id, Direction)`, `DeleteTrack(id)`,
`ImportClips(tracks: List<NewTrackWithClip> | ToTrack(id, clip))` (one edit for a multiple import),
`SplitClip(clipId, atBeats)`, `MoveClip(clipId, toTrack, startBeats)`, `DeleteClip(clipId)`,
`SetTempo(Tempo)`, `SetTimeSignature`, `SetMasterVolume(Percent)`, `RenameProject`,
`SetDescription`, `SetKey`. Non-edits (not in history): `SetMetronomeOn` (saved in the
document, not undoable — FR-035); grid and zoom changes go to `ProjectViewState` through the
repository, never through the editor.

Rules enforced in `apply`: no overlap on a track by editing (move stops against neighbours,
cross-track move requires a free span), split only strictly inside a clip and more than 0.01 s from
its edges, move never before 0, delete track clears solo state if it was the last soloed one.

### Edit history (`core/project/EditHistory`)

`EditHistory(capacity = 50)`: `past: PersistentList<Project>`, `present: Project`,
`future: PersistentList<Project>`; `push(next)` drops the oldest beyond capacity and clears
`future`; `undo()`/`redo()` move one snapshot; `canUndo`, `canRedo`. Cleared when another project
opens; not persisted.

## 2. Timeline geometry (`:shared:core`, `timeline`)

| Type | Purpose |
|---|---|
| `TimelineViewport(pixelsPerBeat, scrollBeats, widthPx, densityScale)` | pure mapping beats ↔ x; `zoomAround(centreX, factor)`, `scrollBy(px)`, clamped to `[fitLevel, closestLevel]` (FR-015: whole project and ≥ 32 bars fit at the widest; one beat ≥ width at the closest) |
| `RulerLabels` | FR-014: given a viewport, tempo map and width returns the bar-row labels (every Nth bar, N a power of two; bars; "bar.beat"; subdivisions to sixteenths), the time-row labels (minutes; seconds; tenths; hundredths) and the tick level below the labelled level; the rule: no two labels in a row closer than their width plus a gap |
| `Snap` | `snap(beats, grid, signature)`; identity for `Off` |
| `ClipHit` | resolves a tap at (x, y) in a lane to `Clip`, empty space, or the playhead marker |
| `TimeFormat` | "mm:ss.hh" for the readout and the time row; "bar.beat" for the playhead chip |

## 3. Engine seam and snapshots (`:shared:engine`)

## 6. Engine-side structures (C++, `app/engine`)

| Type | Purpose |
|---|---|
| `TransportClock` | `int64_t frame`, `bool playing`, `seekRequest` (atomic), `advance(n)`, `applySeek()` |
| `TempoMap` | bpm, beatsPerBar, beatUnit, rate → `framesPerBeat`, `beatsToFrame`, `frameToBeats` |
| `ArrangementSnapshot` (POD, fixed arrays) | `TrackState[64] {gain, audible}`, `ClipState[1024] {track, source, startBeats, offsetFrames, lengthFrames, sourceRate}`, counts; validated at the ABI |
| `ClipSource` | the decoder (`ma_decoder`), its `SpscFifo` (16 384 frames × channels), `primedFrom`, `eof`, `starved` counter |
| `SpscFifo<float>` | single producer (streamer), single consumer (callback); power-of-two capacity; `write(n)`/`read(n)` never block; `available()` |
| `DiskStreamer` | one `std::thread`; `prime(position)`, `stream()`; loop: for each active source, decode into free space; sleep 10 ms when full; stop joins |
| `TrackStrip` | `GainRamp gain` (10 ms linear), `audible` target, `process(in, out, n)` (mono → both at unity) |
| `MasterBus` | `GainRamp master`, sum, clamp ±1 |
| `TransportRenderer` | the callback: apply snapshot/commands at block start; split the block at clip starts/ends; pop fifo frames per clip into the strip; sum into the bus; render the anchored metronome voice after the bus; advance the clock; publish `Seqlock<TransportRecord>` |
| `TransportRecord` | `frame`, `playing`, `blockTimeNs`, `framesPerBeat`, `rate` |
| `AudioDecoder` (offline/worker) | `inspect(path)`, `open(path, seekPoints)`, `read(frames)`, `seek(frame)` |
| `OverviewBuilder` (offline) | decode → min/max int8 buckets → pyramid → `.peaks` file with periodic header flush |

  glyphs the design system lacks (fetched through the script).
